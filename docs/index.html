Student Performance & Risk Prediction System

A Python Desktop Application leveraging Machine Learning to proactively identify students at academic risk before critical exams.

Developed by: Vikas Kummar Khatik (Roll No: 25EJCCS477) | B.Tech CSE (3rd Sem) | JECRC Foundation | Infosys Springboard

About The Project

🤖 Machine Learning Integration

The system utilizes Scikit-Learn classification models (Logistic Regression, Random Forest, Decision Trees) trained on academic datasets. It accurately predicts a student's future performance category and overarching risk level, achieving over 94% accuracy in cross-validation tests.

⚙️ Rule-Based Risk Engine

To ensure explainability, a deterministic rule-based engine runs alongside the ML model. It analyzes 7 key academic factors (Attendance, Internal Marks, Backlogs, etc.) to generate a specific Risk Score (0-100) and maps them into actionable priority recommendations.

🖥️ Modern UI Architecture

Built completely in Python using CustomTkinter, the system features a responsive, visually appealing desktop interface. It includes secure role-based access control, isolating Admin/Teacher environments from Student dashboard views.

📊 Analytics & Reporting

Integrated with Matplotlib and ReportLab, the application dynamically generates visual analytics (Risk Distributions, Attendance Histograms) and automatically exports printable, professional PDF reports for institutional record-keeping.
